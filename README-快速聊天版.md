# 我的 AI 小屋 · 快速聊天版

本版本保留原有 API 管理、登录、语音和图片功能。

聊天优化：
- 主聊天接口启用流式输出，模型一开始生成文字就会显示。
- 聊天上下文从最近 24 条缩短到最近 12 条，减少免费模型每次处理的上下文量。
- 默认最大回复长度设为 900 tokens，避免超长回复拖慢等待时间。
- 如果上游不支持流式，会自动回退到普通 JSON 回复。

注意：免费模型本身的服务器排队/推理速度无法由网页强行加速；这个版本主要减少等待感和额外上下文开销。


### 小红书菜单
当前版本已在主菜单加入「小红书」入口。点击后会进入预留页面提示；正式扫码登录需要先在小红书开放平台创建应用并配置 app_id / app_secret，密钥只放在 Vercel 服务端环境变量中。
